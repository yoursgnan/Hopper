# Hopper — 1-Click Mini Companion Window & Always-On-Top PiP

> **Turn any website into a dedicated 420×760 distraction-free mobile companion window with 1 click.**

Hopper is a **100% self-contained Chrome Extension** with zero external dependencies and zero annoying debugger banners.

---

## 🌟 How It Works:

### 1. 1-Click Pop-Out Mini Window (Top Toolbar Icon)
- Click the **Hopper** icon in your Chrome top toolbar.
- The active tab instantly pops out into a **dedicated 420×760 borderless Companion Window**:
  - **100% Native Mobile Responsive Layout**: Instagram, Reels, DMs, Stories, Odoo ERP, YouTube Shorts, and TikTok adapt instantly without any black empty space.
  - **Zero Debugging Banners**: No annoying "started debugging this browser" bar.
  - **Full Interactivity**: Native video playback with sound, likes, comments, and smooth scrolling.
- Click the **Hopper** icon again to dock the tab right back into your main browser window!

### 2. Always-On-Top PiP Mode (Context Menu)
- Right-click anywhere on the page and select **"Float in Always-On-Top PiP"** to pop out an Always-On-Top floating window that stays in front of VS Code and desktop apps.

---

## 📦 How to Reload the Extension:

1. Open `chrome://extensions` in Chrome.
2. Click the **Reload 🔄** icon on **Hopper**.
3. Open [Instagram](https://www.instagram.com) (or any active tab).
4. Click the **Hopper** icon in your top Chrome toolbar!
