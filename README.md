# Hopper — 1-Click Mini Companion Window & Always-On-Top PiP

> **Turn any website into a dedicated 420×760 distraction-free mobile companion window with 1 click.**

Hopper is a **100% self-contained Chrome Extension** with zero external dependencies and zero annoying debugger banners.

---

## 🌟 How It Works:

### 1. 1-Click Pop-Out Mini Window (Top Toolbar Icon)
- Click the **Hopper** icon in your Chrome top toolbar.
- The active tab instantly pops out into a **dedicated 420×760 borderless Companion Window**:
  - **100% Native Mobile Responsive Layout**: Instagram, Reels, DMs, Stories, Odoo ERP, YouTube Shorts, and TikTok adapt instantly without any black empty space.
  - **Zero Debugging Banners**: No annoying "started debugging this browser" bar.
  - **Full Interactivity**: Native video playback with sound, likes, comments, and smooth scrolling.
- Click the **Hopper** icon again to dock the tab right back into your main browser window!

### 2. Always-On-Top PiP Mode (Context Menu)
- Right-click anywhere on the page and select **"Float in Always-On-Top PiP"** to pop out an Always-On-Top floating window that stays in front of VS Code and desktop apps.

## 📦 How to Install & Reload the Chrome Extension

Follow these steps to load your custom Chrome extension in Google Chrome:

### 1. Open Chrome Extensions
- Open Google Chrome.
- Navigate to `chrome://extensions`.
- Press **Enter**.

### 2. Enable Developer Mode
- Find the **Developer mode** toggle in the top-right corner.
- Turn it **ON**.

### 3. Load Your Custom Extension
- Click the **Load unpacked** button.
- Browse to the folder containing your extension's source code (the folder with `manifest.json`).
- Select the folder and click **Open**.

### 4. Pin the Extension (Optional)
- Click the **Extensions** puzzle-piece icon in Chrome's toolbar.
- Find your extension.
- Click the pin icon to keep it visible in the toolbar.

### 5. Start Using Your Extension
- Open Instagram or any supported website.
- Click your extension's icon in the Chrome toolbar to launch it.

### 🔄 How to Reload After Making Changes
Whenever you modify your extension's source code:
1. Return to `chrome://extensions`.
2. Find your custom extension.
3. Click the **Reload** icon.
4. Refresh the website tab to apply the changes.

**Note:** Keep the extension folder in the same location. If you move or delete it, Chrome may no longer be able to load the extension.
